How I work

Saying it works is not enough; you have to prove it.

Verification first

Nothing counts as done until type checks, linting, unit tests and integration tests against a real server pass.

Written-down decisions

Project state, decisions and runbooks live in files, so nothing depends on memory.

Security scans

03 / About

About me

I'm Yiğit Eren Büyükeren. I develop personal projects across software, systems, self-hosted infrastructure, Raspberry Pi, Android modification, automation, and electronics.

My interests range from PocketBase-based backend systems and services running on Raspberry Pi to Cloudflare and Tailscale infrastructure, web projects, Android root and ROM work, and electronic prototypes.

I don't limit myself to a single field. When a problem catches my interest, I enjoy researching it, building the system end to end, finding its flaws, and turning it into a working result.
