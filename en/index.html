02 · Approach

How I work

Saying it works is not enough; you have to show it.

  1. Proof first

    Nothing counts as done until type checks, linting, unit tests and integration tests against a real server pass.

  2. Decisions in writing

    Project state, decisions and runbooks live in the repository. Anyone coming back months later, me included, knows where to pick up.

  3. Only the data you need

    RideDeck has no accounts or servers; Unfollow Radar never sends data out of the browser. Data that doesn't need collecting isn't collected.

  4. Changes you can undo

    Every step that touches a live system has a way back: a backup first, then a dry run, and a one-command restore if needed.
